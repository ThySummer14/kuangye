# 攒下的日子（第三十七切片）

> 2026-10-04 ｜ 瞭望台 · 成长手记

## 为什么

使命写的是「空虚的反面不是快乐，是能看见自己在变强」。手记原来只有等级条、五维数字和完成列表：一个读了十几天书、还没完成任何一件的人，在瞭望台看不到这些日子。第三十五切片让按天任务不再清零，这一页让所有日子被看见。

## 是什么

成长手记里新增「攒下的日子」：

- 标题「你已经为自己攒下 N 个日子」，副标题起始日期与最长一口气（≥2 天才显示）。
- 按月列出日期小格，只列出现过的日子，不画日历、不推算缺席。金色格表示那天完成了一件事。默认显示最近三个月，可展开更早。
- 点一个日子，看那天做了什么：完成（连同当时写下的一句话）、按天任务攒下一天、累积任务记了多少、书屋摘记、问号夹页线索。只在微光里留下日期的日子（例如后来放下的任务）如实写「这一天留下过记录，细节没有保存下来」，不编造。
- 新账号没有任何日子时整段不出现，手记原有的第一页引导不变。

## 规则位置

`game/journal.js` 的 `gatheredDays / gatheredMonths`：合并 `home.glimmerDays`、进行中与已完成任务的日志、完成日期、阅读摘记、问号线索；同一天同一件事的多次数量记录合并求和。只读投影，不写存档、不发奖励、没有新字段。展示在 `components/GatheredDays.vue`，挂在 JournalView，入口仍是地图 → 瞭望台。
