# 节奏 · 按天任务不再清零（第三十五切片）

> 2026-10-04 ｜ 推倒重做 ｜ 基线 `88e20d2`

## 哪里错了

24 件「连续 N 天」任务的进度曾是 `streakRun`，也就是以今天或昨天结尾的当前连续段。用三周的真实节奏模拟：读书阶段二记了 7 个分散的日子，最近一周没打开，岩壁显示 **「0 / 14 天」**。七个真实的读书日被一笔抹掉。

这正是 CHARTER §3.2「无断签惩罚」和 DESIGN §2.2「不用 streak 断裂制造焦虑」禁止的东西，也是目标用户「断了一天就破罐破摔」的入口：一个从床上爬起来重新开始的人，回来看到的第一件事是自己归零了。两张「免死金牌」只能补昨天，挡不住一周的空档。SERIES.md 早已记下这条矛盾，但当时保留未改。

## 重做成什么

| 方面 | 之前 | 现在 |
| --- | --- | --- |
| 进度 | 当前连续段，空一天归零 | 记录过的不同日期数，只增不减 |
| 完成条件 | 连续 N 天 | 记满 N 天（目标天数不变、难度与奖励不变） |
| 连续段 | 门槛 | 「最长一口气」，只作欣赏，≥3 天时显示 |
| 补记 | 消耗免死金牌，每件 2 张 | 诚实补记昨天：接取之后、昨天还没记，即可补一笔，不消耗任何东西 |
| 岩壁卡片 | 进度条 | 目标几天就有几格，攒下的日子依次填满；今天还没记时下一格轻轻亮着。不画日历空档 |
| 空档后的文案 | 无，只看到 0 | 「上次记在 9月27日。中间空着没关系，攒下的 7 天都还在。」 |
| 地图便笺 | 只能「打开进行中」 | 显示「7 / 14 天」，一键「今天做到了，记一笔」；攒满后直接「收好这件事」 |
| 完成仪式 | 无回望 | 「14 天，散落在 33 天里。停过，也回来了。」加一行足迹点阵 |

24 件任务标题去掉「连续」，按旷野语气改写（如「读满 14 天，每天读 20 分钟」「攒满 30 个 23:30 前入睡的晚上」），目标天数、难度、经验和光都不变；冥想 30 天的说明从「一天不落」改为「坐下来就算，中间空了接着数」。相关出发手册与起步提示同步改为「记满」。这些改写属于 CHARTER §8 的 agent 起草内容，标记 **pending-review**，等用户复核。

## 为什么不是别的方案

- **窗口计数（如 21 天内记满 14 天）**：仍然有一个会过期的窗口，是隐性倒计时。
- **更多免死金牌、自动休息日**：仍以连续为门槛，只是把归零往后推，回来的人还是会面对清零。
- **保留连续语义、只改文案**：文案再温和，「0 / 14」本身就是羞辱。

「记满 N 天」放宽了节奏，但没有降低总量：30 次冷水澡仍是 30 次。习惯养成要的是反复回来，回来这个动作应该被奖励，而不是被清算。

## 规则位置与兼容

- 规则：`app/src/game/rhythm.js`（纯函数：日期去重、最长段、当前段、节奏条、补记边界）。
- 门面：`store.progressOf` 对按天任务返回日期数；`canRecordYesterday / recordYesterday` 取代 `canUseShield / useShield`；完成记录的 `streak` 字段改存最长一口气，`maxStreakDays` 沿用。
- 存档：**零迁移**。日志本来就保存日期，旧档进度只会变多；带 `shield: true` 的旧日志照常算作一天；`active.shields` 保留为惰性兼容字段，导入导出与清洗路径不变。
- 经济：不新增任何发放通道。完成奖励、微光（每个日期一次、七个日期 5 光）、3 件上限都不变。
