# 院落模型细化

2026-09-29，第二十六切片。沿用 `town-models.js` 的同一组模型，地图与院落预览同步显示。

- 木长椅拆成座板、倾斜靠背、扶手、侧支架与黄铜色连接点。
- 小枫树增加分枝、根部、层叠树冠与有尖角、折面的枫叶，并点缀少量落叶。
- 花箱增加分板、横箍、支脚；花朵有花瓣、花心和叶片。
- 路灯增加柱脚、套环、灯笼骨架、屋顶和顶珠，保留暖色发光芯。
- 晾衣架增加横臂、双绳、夹子，两块布有静态垂坠褶皱与缝边，可从两面观看。
- 鸟盆增加底座、过渡柱、连续石质盆沿，水面下沉并有小片反光。

保持原先尺寸与 0/90/180/270 度旋转、坐标、材质缓存、静态合并和独立拾取代理。没有逐帧动画、新纹理、外部素材、依赖或存档改动。布与叶片使用小型 BufferGeometry，包含合并需要的 position/normal/uv。细小接头和缝边用低面数几何；六件合计 10,008 个三角面。该数字是模型本身，不是整场景或真机帧率结论。

## 验证

`npm test`、`npm run build` 的日志在 `output/yard-models-validation.txt`。独立几何检查覆盖六件模型的四个朝向：包围盒都在原占格内，顶点有限，材质合并前后总面数一致；见 `scripts/qa-yard-models.mjs` 与 `output/yard-models-geometry.json`。

1280 / 375 日夜、旋转、三种方案和地图往返无 pageerror、横向溢出或存档变化。手机实际点击 3D 画面中的六件物品，均正确选中对应材料。见 `output/yard-models-browser.txt`、`output/yard-models-picking.txt` 和 `output/playwright/yard-models-*.png`；复放 `scripts/qa-yard-models-browser.js`（5195 开发服务，隔离 `?qa` 数据）。主代理亲看日夜、旋转、地图与方案截图。

首版树冠越格，经包围盒检查发现后收紧到原一格内；首版细部过度使用圆角盒，改为低面数几何后保持观感。原有 three 阴影 API 弃用警告仍在，未重复原生或实体手机性能矩阵。
