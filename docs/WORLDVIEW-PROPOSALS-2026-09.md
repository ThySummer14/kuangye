## A · 归光营地

**主线一句话：** 你与软角在旷野安下一个家，把现实生活里做成的事化作灯光，让附近逐渐成为可以停留的地方。[推演 ← R2、D5、U1]

这不是灾后救援，也没有等你上线才能活下去的居民；它的动力是“这里又多了一处属于我的记忆”。[推演 ← D1、D5]

| 解锁序列 | 场所与玩法 | 依据 |
|---|---|---|
| Lv.1 营地 | 保留当前地图与所有核心店铺；小家承接家具铭牌和五类互动 | 既有功能 R1、R2、R4、D7；营地命名为推演 |
| Lv.3 苗圃农场 | 选择一条已有成长链作为一块花圃的记录；真实进度带来植物阶段变化，不浇水倒计时、不枯死 | 推演 ← R1、D1、D3；不产生新的任务或货币 |
| Lv.5 林间工坊 | 把已完成的创造/生活技能记录整理为可翻看的作品陈列；与买家具分工，重点是“我做过什么” | 推演 ← D2、D4 |
| Lv.7 静水湖 | 从手记选一段回顾，生成一处可重访的倒影记忆；安静停留可先做环境互动，专注钟仅为备选 | 推演 ← R1、D1、D4 |
| Lv.9 归光山坡 | 按月份浏览这一季留下的家具与回顾，在山坡拼成个人营地灯景；灯数不代表全服排名 | 推演 ← R2、D3、D4 |

所有新增区域名称、表现与等级门槛均为推演；等级只是到访资格，不要求按顺序把区域“做完”。[推演 ← D1、D4、U2]

| 角色/设施 | 新叙事里的定位 | 依据 |
|---|---|---|
| 木木师傅与木器铺 | 营地的木作匠，把光换成适合记忆安放的空间；继续办理扩建、墙面和地板 | 既有服务 R4；身份与叙事为推演 ← D5 |
| 林间集市 | 路过营地的旧物与手作摊，让日常成就找到可留存的物件 | 既有家具与旧货 R1、R2；商旅身份为推演 |
| 成长手记 | 营地日志，记录完成与放弃，不写成需要满分的建设考核 | 既有记录 R1；命名与语气为推演 ← D1 |
| 蚀刻章图鉴 | 为一段已完成且有回顾的经历刻一个纪念印记；可追溯原记录，非属性装备、非新货币 | 推演 ← R2、D4、U2；触发条件需另定，不自动双重奖励 |
| 软角是谁 | 第一个与你住进来的“营地守灯伙伴”；会陪你休息与看书，不是催进度的监工 | 推演 ← D1、D7、U1 |

**优势与代价：** 与现有装修闭环衔接最直接，但要靠物件与回顾的细节避免“只有开地”的单调；不需要先构建庞大传说。[方案评估，推演 ← D5]

## B · 逐光航路

**主线一句话：** 你与软角从家门口出发，把人生支线留下的光记在沿途路标上，每次远行都带一段经历回家。[推演 ← D1、D4、D5、U1]

核心情绪是好奇而非拯救世界；离开一阵子，路标仍在，没有黑暗反攻或掉级。[推演 ← D1、D6]

| 解锁序列 | 场所与玩法 | 依据 |
|---|---|---|
| Lv.1 出发小岛 | 现有地图改用旅途起点的叙事；核心任务、家居和档案入口全部保留 | 既有功能 R1、R4；叙事为推演 ← D5 |
| Lv.3 风车农场 | 浏览身体/生活技能的累计记录，以里程路标呈现长期变化；不是农场经营生产线 | 推演 ← D2、D4 |
| Lv.5 路标森林 | 以现有成长链形成可回看的分岔路线；选择关注方向不锁死其他领域，不强迫做全图 | 推演 ← R1、D1、D3 |
| Lv.7 渡光湖 | 在地图上回看已完成经历的时间次序；可挑选一段作为下一阶段的关注方向，先不绑定计时器 | 推演 ← D1、D4 |
| Lv.9 观星高地 | 汇成个人赛季航图，标出回顾与停留；换季开启新一层航图，旧航图可重访 | 推演 ← D3、D4 |

全部等级门槛与区域均为推演。[推演 ← D6、U2]

| 角色/设施 | 新叙事里的定位 | 依据 |
|---|---|---|
| 木器铺 | 出发地的修造所；家的面积与内装继续在此办理，不增加装备耐久消耗 | 既有服务 R4；包装为推演 ← D1、D5 |
| 集市 | 沿途故事的交换摊；买到的家具承接自己的完成回顾，不伪装成他人的在线交易 | 既有购买/铭牌 R2、无后端 R3；包装为推演 |
| 手记 | 个人航行日志，仍是人生累计与回顾，不是地区通关百分比 | 既有记录 R1、D4；包装为推演 |
| 蚀刻章图鉴 | 从人生经历留下的“路标拓印”；收藏的是走过的支线，不能靠点地图批量收章 | 推演 ← D1、D4、U2 |
| 软角是谁 | 天生能感到微光的旅伴，陪你辨认路标；赛季皮肤是沿途气候留下的装束 | 推演 ← D5、U1 |

**优势与代价：** 地图可以成为故事主角，探索意愿更强；需要比 A 更多地域识别与航图设计，也容易使装修退为附属，后续应持续保留“回家放置记忆”的闭环。[方案评估，推演 ← D5]

## C · 四时来信

**主线一句话：** 你与软角经营一座只寄给自己的四时邮局，把每季做成的小事封存成未来可以打开的信。[推演 ← D3、D4、U1]

“信”是本地回顾的叙事形式，不发送邮件、不引入社交私信、也不承诺跨设备投递。[既有边界 R3、D1；信件形式为推演]

| 解锁序列 | 场所与玩法 | 依据 |
|---|---|---|
| Lv.1 邮局前院 | 保留全部当前核心入口，家是邮局旁的住处；手记是本地信匣的原始资料 | 既有功能 R1、R4；空间身份为推演 |
| Lv.3 四时菜圃 | 按月整理已有记录，看到本季不同领域的“收成”；不增加作物养成货币或每日收菜负担 | 推演 ← D2、D3、D4 |
| Lv.5 风声森林 | 从回顾中选一段留作自己未来重读的便笺；到时可打开，也可随时回看，不锁住原记录 | 推演 ← D1、D4 |
| Lv.7 映信湖 | 对照过去与现在的两段记录，强调变化与感受，允许没有进步的答案；专注钟不作为本案核心 | 推演 ← D1、D4 |
| Lv.9 季候阁 | 自选本季代表记忆，编成一封季末信；早期先使用已有文本报告方向，不承诺自动分享图 | 推演 ← D3、D4；文本报告现状见 D5 所在§14“表情与空间”第二段 |

全部等级门槛与区域均为推演。[推演 ← D6、U2]

| 角色/设施 | 新叙事里的定位 | 依据 |
|---|---|---|
| 木器铺 | 修缮住处与信匣的老木匠，实际交易仍只对应既有面积与墙地装饰 | 既有服务 R4；邮局身份为推演 |
| 集市 | 让记忆有实体寄托的物件铺，每张家具铭牌像一张给自己的短笺 | 既有铭牌 R2；比喻为推演 |
| 手记 | 所有信件的底稿与检索入口，完成、放弃都保留，不仅展示“漂亮成果” | 既有 R1；包装为推演 ← D1 |
| 蚀刻章图鉴 | 季末自选经历的纪念邮戳，展示来源与日期；不做每日签到邮票、限时补票收费 | 推演 ← D1、D4、U2 |
| 软角是谁 | 邮局的保管员兼室友，帮你守着还没想好怎样讲述的经历；换季换小小的工作装束 | 推演 ← D4、D7、U1 |

**优势与代价：** 最适合手记与蚀刻章，温柔且有长期辨识度；阅读和书写比重更高，需要克制文案量，避免打开网站就要写作文。[方案评估，推演 ← D1、D4]
