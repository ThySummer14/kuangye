# 房屋建筑细化

2026-10-03，第三十三切片。按用户要求打磨建筑精细程度。地图中的小家、街角书屋、小小画室和木器铺共用 `building-models.js`，沿用原有场所、位置、配色与书屋修复条件。

## 看得见的变化

四栋房屋采用同一套木作与石作语言：坡面和山墙对齐，瓦片有错缝、叠压与轻微色差，屋脊分段；檐口、斜撑、四面石基、转角立柱、窗框和窗台都有独立厚度。门增加门套、嵌板、铰链、把手和信口；圆形阁楼窗保留营地小屋的柔和轮廓。

- 小家：侧墙与背墙补窗，百叶窗有叶片与铰链，窗下花箱有土面与小花；烟囱增加砖缝、泛水、烟道开口和压顶；有顶门廊改为瓦顶与斜撑，露天门阶保留木板台阶，檐边增加雨槽和落水管。
- 书屋：四个修复阶段仍各自可辨认。初始窗上有钉板与门前散木；打开后清理遮挡；第二阶段增加有书脊细节的室外书架和带靠背的长椅；第三阶段加瓦顶门廊、两盏悬灯与暖色窗面。
- 小小画室：增加屋顶天窗、大侧窗和圆窗，门前有颜料罐与画笔，让房屋本身能说明这里的用途。
- 木器铺：四面木板接缝、工作台横撑、台钳、锤子、叠放木料的端面与角尺招牌，让它与画室和住宅区分开。

院落里的「搭配房屋」自动进入小家近景，切回布置或方案恢复院落全景；书屋预览也采用更近的镜头。日夜、旋转、缩放和复位仍使用既有控件。镜头与光线只在页面内变化，不写入存档。

## 几何与资源
