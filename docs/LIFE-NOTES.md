# 先理顺一个小地方

第二十九切片：六件原创 pending-review 草稿，仅本地 Vite `?qa` 独立任务池可见。入口为地图 → 岩壁 → 把生活理顺。按真实卡点选择场景，每次只展开两件，默认岩壁不增加长列表。

| 场景 | 小事 | 完成产出 |
| --- | --- | --- |
| 总在找东西 | 给三件小物安个家 | 三个固定位置，各模拟取用归位一次 |
| 总在找东西 | 重要纸张位置索引 | 三份名称与位置，按索引找回一份 |
| 临出门才忙 | 试走出门前的几步 | 三至五步流程，两次试走、一处调整 |
| 临出门才忙 | 常去地方的替代路线 | 查清路线、转折／换乘及临行需核对的信息 |
| 到饭点没主意 | 两个吃饭选项 | 两个现实方案及时间／地点／准备条件 |
| 到饭点没主意 | 先看库存再采购 | 一处自有食品区盘点与采购判断，可如实为空 |

与既有桌面清理、电子文件归类、明日物品准备、学做菜不同，本组着重建立固定位置、查找索引、验证动作顺序和提前减少选择困难。每件包含三步手册、卡住时的起步办法、专属回顾问题；无需新工具、厨房、上传私人信息或额外消费。内容中的地图、营业信息由用户行动时核对，产品不提供实时信息。

复用 store canonical task、三任务上限、saveActionPlan、完成及回顾，不新增持久化字段或依赖。六件均为非重复 E 级，QA 合计上限 60 XP／30 光；正式任务池不增加奖励，复核后纳入时须看整体预算。试用库由 21 件增为 27 件。
