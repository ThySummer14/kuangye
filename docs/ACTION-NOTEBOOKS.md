# 行动小册 · 从情境走向行动

2026-10-03。入口仍是地图 → 任务岩壁 → 一个生活方向，普通模式可用。

此前普通模式点方向只筛选几张任务卡，而场景小册仅在本地 `?qa` 展示。内容增加了，日常入口却仍显得薄。第三十一、三十二切片把原有任务组织成五本行动小册，让用户先辨认眼前的情境，再选一件事，不需要先在完整库里做筛选。

| 方向 | 三种情境 |
| --- | --- |
| 出去透口气 | 就在附近、换种体验、再走远些 |
| 把生活理顺 | 拖着的小事、照顾日常、找到节奏 |
| 做点自己的东西 | 找个开头、动手做出、收好一版 |
| 靠近一个人 | 说出心里话、留段时间、听听自己 |
| 给头脑留点时间 | 读不进去、想弄懂一点、想把学的留下 |

每种情境呈现两件候选，十五种情境共引用 29 件不同的原有任务；“一个人吃一顿正餐”在出门与听听自己中均可找到。这是原有任务的新组织方式，没有新增有奖任务或奖励通道。小册呈现完成条件、记录方式和第一步，手册继续提供完整步骤、起步提示与回顾。两轮共为十三件原有任务补专属手册；半天志愿活动、三次二十分钟散步、十次新词使用、三千字综述与讲述等原要求保留。

小册保留任务状态：已接下时直接回到上方对应任务并恢复焦点；已完成时可以翻阅手册，继续由 `canAccept` 阻止重复接取。其他暂不可接取的原因会出现在纸页下方。普通模式选中方向后先收起列表，想继续找时展开该方向任务；原方向内的任务仍保留，不只列小册里的六件。搜索、领域、用时与地点筛选继续可用。

情境底部可“自己写一件”。十五组参考写法只作为输入框提示，不自动填入或接取任务；用户写下自己的目标、完成条件、时机与第一步，继续走原 `createPersonalTask` 门面与三个名额上限。编辑原任务和从页首打开空白表单不会残留情境提示，自建任务不另发 XP 或任务光。

头脑小册进一步接到书屋：阅读情境去阅读桌，其他两种情境去[问号夹页](INQUIRY-DESK.md)。有正在读的书或正在追的问题时，纸页展示真实书签／下一步。书屋回岩壁会恢复头脑方向，继续已接任务时聚焦对应卡片；从夹页带回下一步则预填自建任务的第一步，目标与完成条件仍由用户自己写。

桌面采用左侧情境、右侧两张纸页；375px 情境按钮横排，说明在按钮下完整显示，纸页纵排。日夜沿用原有浅色纸页，不新增暗色主题。

声明在 `data/trail-notebooks.js`；`TrailNotebook.vue` 只读展示，`QuestView.vue` 编排导航和弹窗。任务身份、奖励和接取资格继续由既有 data/store/game 层负责。小册本身不写存档，书屋夹页使用可选 v3 `home.inquiry`，旧档为空夹页；没有新增依赖或不可逆迁移。

本地独立浏览器 fixture 的定向主路径覆盖十二种情境、只读翻阅、列表展开与焦点、手册接取、便笺回地图、5 光完成、刷新与重复禁接取、自建任务与便笺恢复、日夜。两种宽度无 pageerror 或横向溢出。证据为 `output/trail-notebooks-browser.txt`、`output/playwright/trail-notebook-*.png`，复放脚本 `scripts/qa-trail-notebooks.js`。基础检查见 `output/trail-notebooks-validation.txt`。未重复原生或实体机检查。

新增头脑方向的普通模式主路径覆盖三个情境、两件候选、书签接续、问题线索、历史收好／继续、下一步转自建、准确任务焦点、刷新及备份往返。证据为 `output/brain-inquiry-browser.txt`、`output/playwright/brain-*.png`，复放 `scripts/qa-brain-inquiry.js`，基础检查见 `output/brain-inquiry-validation.txt`。
