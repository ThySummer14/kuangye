# 院落布局方案

入口：地图 → 院子 → 布局方案。现有六件材料免费各一份，不增加地图建筑或导航入口。

三种方案分别围绕树下座位、晾衣生活、树与鸟盆安排。卡片提供平面示意和描述，点击后自动露出立体预览与确认区，可旋转、缩放及切换日夜。键盘焦点移到预览标题，取消回方案卡，采用回材料选择。

预览完全是 YardView 局部状态，不写入 town；切换面板、取消、离开都会丢弃预览。只有「采用这个布局」调用 store.adoptYardPlan，game 层先完整验证，再一次替换 yard。房屋外观、书屋、家具、任务、光均不变。方案不以 id 持久化，存档仍是原有位置列表，旧档无需迁移。采用后仍沿用单件摆放、旋转、移动与收回。

声明位于 data/town.js，合法位置继续由 game/town.js 的 yardCheck 判定。方案生成独立副本，非法或重复材料不能部分写入。预览时关闭地面选格交互，避免误以为正在手动编辑。
