# 一生去挑战 · 十四枚专属蚀刻章

2026-10-07。用户给出十四项愿意用一生挑战的目标，明确每项单独设计。完整目标、章名与铭文见 `app/src/data/lifetime-challenges.js`。这是人生挑战专辑；原六项加码行动的四枚章继续使用原图集。

## 原创与建模方式

内置 imagegen 分别生成十四张透明正投影 PNG，每项使用独立构图提示。参考输入只有本项目先前生成的原创 `engraving-atlas.png`，用于统一薄边框和刻线工艺。没有复制方舟章图或平台标志。先前提供的方舟参考阅读与取舍见 [美术参考记录](../challenger-3d/refined/README.md)。所有提示词在本目录 `{life-id}.prompt.txt`，生成原件来源在 [sources.json](sources.json)，原件保留于生成目录，项目复制件在 `app/public/challenger/lifetime/`。

每张独立原图映射到真实浅浮雕：透明边界决定六角 UV，亮度采样改变正面 55,296 个三角面的高度，配合金属侧缘、双层接缝、240 道滚花、背扣、刻度与独立编号。精细图案的刻线来自生成纹样，不声称每根线都独立手雕。主体按材质合并为五个 mesh，背铭另一个，约 6.8 万三角面。可以旋绕、放大、观察正面和背面。

列表只加载各约 70–76 KiB 的 WebP 预览，十四张约 1 MiB。预览由同一 three.js 模型渲染，不是另一套平面设计；运行开发服务器 5192 后用 `node scripts/render-lifetime-medals.mjs` 重建。原图各约 2.3–2.6 MiB，仅在打开对应详情时加载。CPU 解码缓存最多三个源，GPU 纹理和上下文随详情关闭释放；等待、加载失败、GPU 失败均有静态预览及恢复路径。

## 验收边界

纯模型测试覆盖全部十八枚章的有限几何、厚度、法线、UV、材质合并及逐资源释放，另验证采样确实改变顶点高差。浏览器在桌面和 375px 打开全部十四枚新章，检查对应图案、背面、键盘、reduced-motion、只读存档和上下文释放。共享观察器的拖动、缩放、模拟双指、加载取消与失败重试由旧四章回归覆盖。实体手机的 GPU 性能和触摸手感仍未验证。
