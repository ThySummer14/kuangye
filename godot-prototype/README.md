# 旷野 · 原始 Godot 小镇试作

这份工程恢复自 2026-10-08 的原始私有工程备份，源状态对应本地提交 d42d269852eccde0ac440dc480928e1748ad5225。它是 `godot-prototype/` 原型，与另一独立实现 `godot/` 分开。此分支不修改现有 `app/` 或 main。

## 恢复边界

本提交是可信备份的运行源码基线。后来的光照、地板与小芽五官表面修订未进入这份备份，需要另一个增量提交重新实现和验证，不能把它称作完整恢复后的最终图形稿。测试输出、测试存档、机器缓存和通信记录不进入本分支。

## 运行

使用官方 Godot 4.6.3 打开本目录的 project.godot。WASD / 方向键移动，点击建筑走到入口，E 互动，B 布置，R 旋转，Esc 取消；N 随手记。手机使用摇杆与屏幕按钮。

可进入三处室内、向木匠购买家具、回家摆放/移动/收回、保存重开，并把真实观察写进小记。小记历史在同一记录窗口内分页回读。原型有独立存档，不读取或迁移 Web/Android 数据。

## 检查

从仓库根运行 `python3 godot-prototype/tests/run_all.py`，隔离用户存档运行无图形检查。无图形测试不等于图形、手机输入法或真实设备性能验证。
