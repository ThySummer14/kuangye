# v7.2 界面布局与验证

基于原始 Godot 分支的 v7.1（460f10cf）出口热修，保持存档 VERSION=2。本轮只改界面，不迁入尚未完成的徽章或动作草稿。

## 变化

- 桌面作品阅读居中、宽度最多620px，短文按内容决定高度；长文在可用高度80%内滚动。
- 手机作品阅读采用安全区内下方展开，编辑时标题/关闭/确认固定，正文滚动。作品编辑与作品集入口同一轻行。
- 常驻记录位于右下、附近互动位于底部中间；开面板时隐藏世界摇杆和快捷按钮，布置模式只留当前编辑操作。
- 横屏键盘高度代理仅剩195px时，缩减内边距与间隔，保留至少44px触点和58px正文带；跟随焦点滚动到输入框。
- 关闭释放文字焦点；未保存文字暂留本次会话，未写入存档。确认后写盘，空白已完成作品不能覆盖原成果。

## 验证边界

12组离线检查全部通过，其中包括59项创作检查、29项实际物理出口回归，以及42项本轮UI断言；这些计数相互包含，不能相加。UI断言使用实际根窗口1280×720、375×812、812×375，检查完整矩形、安全区、固定确认与关闭、极矮编辑正文可见区域、取消重开、空白拒绝、磁盘重新加载和长文滚动。

原生最终42项全部通过，10张场景截图已复核；运行12.96秒，峰值477MiB。测试驱动在真实窗口中检查控件矩形并触发动作，属于桌面图形回归，未代替用户手指操作。系统软键盘高度通过替代值模拟，云端窗口不等同于手机实机；输入法组合输入、键盘真实弹出/收起以及物理设备性能仍需观察。测试内容仅在隔离测试目录，不进入初始用户存档。

## 复用经验

按内容收紧面板时，必须在文字换行布局完成后再次测量最小高度。只断言关闭与确认矩形不够：极矮键盘视口可能让正文只剩一条标签，因此还要断言滚动区域高度和已聚焦输入框的可见交集。世界像素视口与清晰UI分开缩放，避免文字随世界降分辨率。
