# 本轮浏览器验收（2026-09-25 开始，运行跨本地午夜）

环境：官方 Browser Use，ZCode IAB；本地 `http://127.0.0.1:5182/?qa` 一次性测试存档。未访问生产存档。主代理逐张检查原始视口截图；PNG 从工具产物原样复制，没有拼接、裁剪或修改。

## 已实测

- 1280px 地图进入任务岩壁、接下第一次2公里慢跑。完成表单写回顾“发布准备回归：慢慢跑完，记住路边的树。”，确认后得到15光、25XP、1条完成记录。
- 375px 结果页完整显示小芽、奖励、回顾、保存提示与自然结束按钮；按“收好了，回到地图”返回，品牌按钮获焦。刷新后仍为15光、1条完成记录。
- 通过已有 `#home` 路由直接访问小家（不把这一步记成地图导航通过），光线选项分别选择午后晴光和温柔夜晚，刷新读取保存后的真实设置。桌面1280×900、手机375×812四张日夜截图主代理亲核，角色和场景可辨识，没有本切片造成的布局改变。
- 375px地图与1280px小家测得 document scrollWidth 等于 innerWidth，无页面横向溢出。

## 未完成与环境失败

- 官方浏览器不向子代理开放，子代理返回 `Browser is not available in subagent`，故全部浏览器操作由主代理完成。
- IAB语义click多次timeout，键盘press未触发结果；原始截图坐标点击成功完成任务流程。
- 刷新后的地图点击手记进入飞行中间态后停住。页面 visible、hasFocus=true，但独立 requestAnimationFrame 探针在1500ms内没有回调。截图 `map-animation-stalled-375.png` 保留中间态（标题/部分标签裁切），不视为地图验收通过；不能据此宣称完整 navigation/journey/completion-exit 脚本矩阵通过。根因尚未确定是宿主渲染暂停还是产品生命周期问题，下一轮须复现。
- 当前IAB不支持文件上传，未在Web重跑完整备份导入往返；同一轮原生XCUITest完成真实系统选择器导出/导入，证据在 `../native/`，不将原生结果冒充Web结果。
- IAB fullPage截图出现重复拼接，已弃用；只保留真实视口图。桌面日景一次截图30秒超时，之后重取成功。
- 没有完整收集浏览器console/pageerror，本轮不声明“无pageerror”。未执行真机性能测试。
