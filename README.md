# 旷野 · 小芽的家

完成生活里的小事，收集一点光，为小芽布置一个温暖的小家。

旷野 v3 把原有的人生支线任务接进一个可探索的 3D 小岛：任务岩壁、林间集市、小芽的家和瞭望台。家具不只是奖励，第一次完成任务后的首次购买会把那段回顾记在家具铭牌上。

## 可以做什么

- 拖动、缩放 3D 小岛，点建筑或场所标签进入；桌面与手机都从地图进入，子页可以轻量返回地图。
- 今日入口精选五领域各一件低门槛任务；完整任务库、搜索、成长线、连续打卡和累积记录继续保留。同时最多接 3 件事。
- 完成任务收获光；在四个摊位选择 20 件可购买家具。另有 Lv.3 / 5 / 7 / 9 的 4 件成长赠礼。
- 从第一天就拥有一间 3 × 3 米的小屋，可花光向两个方向逐次扩建，最大 6 × 6 米。以 0.5 米网格摆放家具，支持 90° 旋转、移动、收回背包和按实付价格 70% 回收。实体家具不能重叠，地毯可以垫在家具下面。
- 直接点击 3D 地面放置，也可用平面格子与键盘操作。方向键选择格子，R 旋转，Esc 取消当前布置。
- 小芽采用已选定的02「软角」暖白通用形象，有14种情绪，表情采用保留速度的阻尼弹簧插值，包含眨眼、呼吸、视线跟随与摸摸互动；3D 小芽也使用同一套表情参数。
- 小芽的本子记录完成回顾和暂时放下的任务；查看五维属性、累计生活记录，导出成长报告与 JSON 备份。

## 光与记忆

任务结算奖励为 `round(xp × 0.6 / 5) × 5`，对应 E–S 难度获得 5 / 15 / 30 / 60 / 120 / 300 光。草席定价 5 光，第一件 E 级任务即可换到。

每个有记录的日期只记一次微光，累计七个日期再获得 5 光。日期不必连续，中断不会清空。打卡、有效数量记录、补记和完成会登记日期；放弃不扣光、不奖励光。

每条完成记录最多绑定一次新购物品的铭牌。回收家具不会删除任务手记，赠礼不能回收或购买。旧货摊的三件旧物七折售卖，顺序由日期和赛季种子确定，没有倒计时或绝版压力。

## 保存与迁移

游戏数据保存在当前浏览器 `localStorage` 的 `kuangye.v3`，无业务后端、无游戏账号、无云同步。Sites 的站点访问控制独立于游戏存档。

第一次打开会读取 v3；损坏时依次尝试 `kuangye.v2` 与 `kuangye.v1`。旧版键保留不覆盖，历史已完成任务会折算为起始光余额。导入 v1/v2/v3 JSON 统一经过白名单清洗；当前任务、小家库存、摆放位置与铭牌一起导出。恢复备份前，界面会确认替换，并先自动导出当前数据。

**不同网址不能直接读取彼此的浏览器存档。** 从旧 GitHub Pages 迁移到 Sites 时，先在旧网站导出，再在新网站的「成长手记 → 导入备份」恢复。无痕浏览、清理浏览器数据或换设备前也应备份。

## 开发与检查

运行时依赖仍只有 Vue 3 与 three.js；无外部模型或贴图。家具图来自同一套 3D 模型的本地渲染。

```bash
npm --prefix app ci
npm run dev        # Vite 开发服务器
npm test           # node:test，31 项逻辑、存档与场景回归检查
npm run build      # 构建 app/dist，再生成 Sites 使用的根 dist
```

根 `.openai/hosting.json` 保存 Sites 绑定，`static.directory` 为 `dist`。发布使用构建后的静态产物。GitHub Pages 工作流仍在 `.github/workflows/`，本次发布同步推送到 GitHub；推送 main 也会触发现有 GitHub Pages 工作流。

## 小家生活更新（2026-09-13）

当时采用绿色种子与双叶轮廓；当前外观已由下文第二轮选定的暖白软角替代。小芽安静站立，点击角色可摸摸；选择家具后可浇花、坐下、打盹、读书或随收音机摇摆。发现会保存在成长手记，重复互动不产生货币。

房间可拖动旋转及调整俯视高度，支持滚轮／双指缩放和按钮控制。上半墙与窗帘、灯串、画框作为同一个剖切组随视角淡出，避免墙饰浮空；自由摆放的挂毯增加落地木架。四种墙色、三种地板和三种光线免费切换。

扩建从 30 光起，每次提高 20 光；每次沿选中方向增加一米，家具保留网格坐标。`game/room.js` 管理扩建与装饰存档，`game/buddy-walk.js` 管理可行走区域与路径，`scenes/home-life.js` 将路径、互动和支撑面阴影接到角色。

## 装修师傅与窗外天气

从地图进入「木器铺」，找木木师傅办理扩建、换墙面和地板。天气默认通过浏览器授权获取设备附近位置，坐标取两位小数用于 Open-Meteo 查询；拒绝、超时或不支持定位时回退新乡。定位仅在内存中使用，不写入存档。网络失败会显示同步失败，并保留上次数据或明确标注临时晴天。

时间默认按 UTC+8 每半分钟更新，光照随时间变化；支持自选晴、云、风、雨、雪、霜、月夜及日间、日落、夜间光线。室外模型天气每半小时刷新，不是设备自带的气象传感器读数。天气与手动偏好随 v3 存档保存。

小芽取消身体深度压缩；朝向采用最短角度过渡，动作使用当前姿态连续追随。眨眼和嘴形连续变化。设计参考 moodstone 与 bloub 的分层姿态、非对称眼形和眨眼节奏，未复制项目资产。

## 2026-09-14 执行批与交接

地图是唯一主入口，子页统一返回地图。小芽不再自动游走或响应空地点击，家具主动互动保留平滑靠近；音乐互动保留摇摆、不再蹦跳。木器铺独立办理装修，价格与 v3 保存规则保持不变。

当时按用户要求暂停白眼方案。用户随后选定02「软角」并授权继续，当前已恢复形象实现与试验台发布；历史取舍见 [RUNLOG](docs/RUNLOG-2026-09.md)。

本地一次性检查：启动 `npm --prefix app run dev -- --host 127.0.0.1 --port 5182 --strictPort`，用 Playwright CLI 打开命名会话 `kuangye-batch`，运行 `node scripts/run-browser-qa.mjs navigation` / `woodshop` / `home` / `emotion`。前两项对应地图与木器铺；最后一项检查当前平面与立体试验台。`?qa` 仅开发服务器生效，使用独立存档、禁用天气联网。

## 第二轮 · 暖白软角（2026-09-19）

四方向概念与保留 idea 见 [设计档案](docs/ideas/mascot-directions.md)。已选择02：两个不等高的圆钝短角、饱满闭合身体、小型深色五官和浅桃色脸颊。身体调为暖白，减少褐色阴影；用少量环境补亮保留夜间体积，不能把形象拉成扁片。

地图「小小画室」进入独立表情试验台，可以查看14种情绪、任意两种过渡、暂停与循环、调节速度/阻尼，切换平面和可拖动旋转的立体预览；返回地图仅需一击。试验台不加载游戏 store。主站 BuddyFace 与3D角色共用情绪、面部轮廓与暖白配置。

`game/mascot.js` 管外观与闭合轮廓，`game/emotions.js` 是情绪参数的单一来源；赛季皮肤不拥有情绪或互动状态。目前只有已选02默认皮肤，没有新增换肤商城。3D身体、五官和柔和接触阴影均为程序化几何，没有角色贴图；bloub 两个几何辅助函数保留 MIT 许可，moodstone 和 momo 仅作节奏/体积参考。

第三轮仅交 [世界观候选文档](docs/WORLDVIEW-PROPOSALS-2026-09.md)，尚未实施区域解锁、剧情、蚀刻章或新任务。
