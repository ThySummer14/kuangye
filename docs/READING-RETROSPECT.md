# 阅读回望

书屋阅读桌下方增加阅读回望，沿用地图 → 书屋入口。读完和暂放的书按最近记录日期排列，可按状态、有摘记筛选，并搜索书名、作者与摘记正文。卡片展示书名、作者、日期和最近摘记；展开后按日期正序串起开始、摘记及读完／暂放节点。

没有摘记或日期时如实显示，不生成阅读内容或推算阅读天数。暂放的书保留下一步线索，已读完的书不把旧下一步当成新任务。可从回望带回阅读桌补写，返回列表恢复卡片焦点与筛选状态。书籍重读仍沿用既有语义，清空 finished；没有新增独立重读历史。

只读使用 home.reading.books；不增加存档字段、迁移、奖励、依赖和入口。未有归档书时说明如何开始，不向实际存档插入示例书。

验收：一次 npm test、npm run build；1280/375 独立 ?qa fixture 检查空状态、摘记搜索、无结果恢复、暂放筛选、时间顺序、焦点恢复、带回阅读桌、地图往返、日夜切换、无溢出及翻阅前后 home 相同。截图使用自写示例，不是产品内置书籍。脚本 scripts/qa-reading-retrospect.js；证据 output/reading-retrospect-{browser,validation}.txt 与 output/playwright/reading-retrospect-*.png。未覆盖真机性能。
