# 走出房间时掉落：复现与热修

用户报告进入房间后再往外走会掉下去。以公开 v7 游戏源码复现，未混入徽章开发。

根因：三个室内的地板碰撞到 z=4.2 结束，门口踏板仅有显示网格；方向键/摇杆可以从前墙开口继续走出，但没有自动门槛过渡。角色会在仍为室内场景时跌到 y≈−10。按 E 或点击现有出门按钮的显式过渡没有同样问题。旧集成测试只取消了出门过渡、没有实际走过门槛；换场压力测试只检查资源与节点，遗漏了持续触地检查。

热修只改变门口行为：
- 行走穿过 z=3.6 门槛时启动已有的返镇过渡；显式 E/按钮照常。
- 门槛增加真实落地碰撞及后侧保护，不再是悬空的装饰网格。
- 取消自动过渡后保持取消状态；继续按方向仍站在有支撑的平台。走回室内后可再次穿门，或直接按 E/点出口继续。

不改变人物造型、奖励、作品、用户存档格式或场景坐标系。鼠标/键盘、合成摇杆输入分别检查；合成触屏不是实体手机测试。

最终验证：11组聚合检查全部通过；原生375×812窗口的29项出口专项通过，覆盖三屋方向键/摇杆直接出门、每次只有一个世界、取消后持续按键仍站稳、鼠标再次出门、踏回屋内重新触发。原生运行30.71秒，峰值约451MiB；无实机性能结论。
