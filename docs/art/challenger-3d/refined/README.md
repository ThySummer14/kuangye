## 原创资产与真实模型

使用内置 `imagegen`，没有外部付费 API / CLI 回退。先生成 [原创设计板](concepts.png)，完整提示词见 [prompt.txt](prompt.txt)；再将该原创板转为正投影材质图集，提示词见 [atlas-prompt.txt](atlas-prompt.txt)。最终图集存于 [`app/public/challenger/engraving-atlas.png`](../../../../app/public/challenger/engraving-atlas.png)，透明 PNG，1254 × 1254，约 2.8 MiB；只在打开立体观察时加载。图像展示门与阶梯、新芽与岩隙、交汇星轨、云海山径四个独立故事。

实时模型采用**原创纹样贴图 + 采样浅浮雕 + 独立金属结构**。正面以图集六角地标映射 UV，亮度采样形成真实顶点高差，六个扇区共 55,296 个三角面，法线随几何起伏变化；不是一张始终朝向镜头的图片。精细刻线和色彩来自原创纹样贴图，不声称每根叶脉或每一道山纹都手工雕成独立零件。它是薄章的浅浮雕工艺，并非完整体积雕塑。

外框倒角、双层侧缘、240 道独立滚花、背面环形刻度、扣针、针座、卡扣、序号刻痕都是单独建立的几何；主体按材质合并，五个 mesh（背面铭牌另一个）。每枚总计约 6.8 万三角面。GPU 只在一个详情窗口内工作，静止时不连续渲染；隐藏页面或离屏暂停巡回。使用既有 Vue / three.js，没有新依赖。

首屏、列表、回退图样来自同一模型的透明渲染，四张 `app/public/challenger/{motif}.png`。改模型、材质或灯光后，启动 5192 的 Vite，再执行 `node scripts/render-challenger-medals.mjs`，随后构建。脚本通过现有 Playwright CLI 创建全新上下文并固定像素比，避免模块缓存和系统像素比令缩略图与模型不同步。

## 验收与边界

133 项测试通过，包含非恒定纹样采样确实改变顶点高度、UV 范围、有效法线、薄章厚度、材质合并、差异和纹理／几何／材质各释放一次。浏览器检查桌面和 375px 的四枚章、旋转、缩放、正反面、键盘、触控模拟、reduced-motion、只读存档、上下文释放和回退重试；追加检查加载途中关闭不晚创建 WebGL，以及图集加载失败后的重试。

完整操作与发布记录见 [挑战者说明](../../../CHALLENGER.md) 和 `output/challenger-refined-*`。实体手机 GPU 和实际触控硬件性能尚未验证。
