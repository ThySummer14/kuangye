# 相处小册 · 把自己的话说清楚

六件原创 `pending-review` 草稿，开场时已有实现与独立试用证据，本轮补齐归档。仅本地 DEV + `?qa` 可使用，不进入普通或正式任务池。

按不知怎么说、想认真回应、需要些边界三种情境，每次给出两件事：表达偏好、说明协作安排、回应搁置消息、给作品具体回应、明确小拒绝、说明方便联系的时段。每件包含准备、三步行动、起步办法与专属回顾。不是已有感谢、邀约、近况分享或倾听任务的改名。

完成只依据自己的实际表达，不要求对方回复、同意、原谅或接受。写草稿不替代实际表达，不为任务制造请求或冲突，没有适合情境可留到以后。产品不接入通讯录、不代发消息，也不记录对话内容。

沿用 `SituationFieldNotes`、`TaskGuide`、出发便笺和既有结算。六件 E 级一次性草稿在隔离试用池内合计最多 60 XP / 30 光，无新奖励通道；待审内容共 39 件，正式预算不变。正式纳入前需按维护契约复核内容与整体预算。

代码在 `data/connection-tasks.js`，入口是试用模式岩壁的“靠近一个人”。开场已有证据 `output/connection-browser.txt` 与 `output/playwright/connection-*.png`；本轮定向验证另存 `output/trail-notebooks-connection.txt` 与 `output/playwright/trail-connection-*.png`，不覆盖原证据。
