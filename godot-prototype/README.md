# 旷野 · 原始 Godot 小镇试作

这份工程恢复自 2026-10-08 的原始私有工程备份，源状态对应本地提交 d42d269852eccde0ac440dc480928e1748ad5225。它是 `godot-prototype/` 原型，与另一独立实现 `godot/` 分开。此分支不修改现有 `app/` 或 main。

## 恢复边界

工程先恢复可信 v4 源码基线，再以独立增量重建小芽五官表面、光照、地板与竖屏镜头。v6 已在云端原生 1280×720、375×812 窗口完成各 14 项玩法闭环检查并留下实际截图；窗口尺寸检查不等同于手机实机。重建来源、改动与画面限制见 [docs/RECOVERED_GRAPHICS.md](docs/RECOVERED_GRAPHICS.md)。本轮 v7 在此基线之上迁移文字观察与创作流程。测试输出、测试存档、机器缓存和通信记录不进入本分支。

## v7.4：蚀刻章柜与完成记录

从作品集或小家书架打开章柜。18枚原章可查看条件，本轮支持小说挑战和实地求证：接取冻结条件、关联作品与观察、本人写结果并逐项确认，再留下完成记录。实际可解锁世界落笔、越界者、淬火意志；其余15枚标明尚未接入，旧8系列仍仅预览。

证据用于本机记录，不代表系统验证了整本小说或现实访问。重复确认不重复发奖，历史副本不随原文修改，保存失败可在面板内重试。原存档分文件迁入以保留回退快照，详见下方迁移说明与 [章柜规则](docs/BADGE_RULES.md)。

## v7.3：小芽回应你的动作

沿用原形象与情绪参数，接入自在、好奇、开心、骄傲、专注五个上下文。小芽会呼吸与眨眼，走动时轻轻摆身；写字时安静下来，保存记录或完成作品后，等你关上面板再作出反应。失败保存不播放成功动作，换房和失焦清除旧状态。其余9种情绪只有映射记录，尚未开放。详见 [动作来源与验证](docs/MASCOT_MOTION.md)。

## v7.2：按内容阅读与编辑

作品阅读在桌面居中，短文自动收紧，长文最多占可用高度的80%后滚动；手机在安全区内靠下展开。编辑和作品集放在同一轻行，主确认固定；输入时隐藏世界摇杆与快捷按钮，布置模式只显示编辑工具。极矮键盘视口压缩间距，保留44像素触点与可编辑正文区域。存档格式沿用v7.1，退出房门热修保留。详见 [界面验证](docs/RESPONSIVE_UI_QA.md)。

## v7.1：走出房门

修复方向键或摇杆直接从室内门口走出时掉落。现在穿过门槛会回到镇上；取消过渡后，门外踏板有真实碰撞支撑，出口按钮仍可继续使用。原生29项出口回归与11组离线检查通过，详见 [出口热修](docs/ROOM_EXIT_HOTFIX.md)。本次不改变用户存档字段。

## v7：观察到作品

随手记中的「观察册与作品集」、镇上长椅、画室画架都能进入：地点/日期/发现 → 收进观察册 → 带素材开始创作 → 正文/私语 → 确认完成约定 → 陈列到小家书桌。最多3项进行中，暂放和继续保留成果；原观察后来改动不影响当时素材。作品完成与随手记共用每日一次5微光，不重复发奖。

本轮为文字流程。图片、导出、18枚已实装蚀刻章等仍待分阶段迁移，见 [功能清单](docs/FEATURE_PARITY.md)。59项定向离线检查、10组聚合检查通过；原生57项检查与6张截图通过，两者不相加。实际手机输入法/设备性能仍待验证。详见 [v7 QA](docs/CREATIVE_SLICE_QA.md)。原型v1存档可兼容读入，未接入原Web/APK v3导入。

## 运行

使用官方 Godot 4.6.3 打开本目录的 project.godot。WASD / 方向键移动，点击建筑走到入口，E 互动，B 布置，R 旋转，Esc 取消；N 随手记。手机使用摇杆与屏幕按钮。

可进入三处室内、向木匠购买家具、回家摆放/移动/收回、保存重开，并把真实观察写进小记。小记历史在同一记录窗口内分页回读。原型有独立存档，不读取或迁移 Web/Android 数据。

## 检查

从仓库根运行 `python3 godot-prototype/tests/run_all.py`，隔离用户存档运行无图形检查。无图形测试不等于图形、手机输入法或真实设备性能验证。

## 干净打包

`python3 godot-prototype/tools/package_delivery.py --web-dir /path/to/dist --output /path/to/new-delivery.zip` 按明确白名单打包，不遍历整个仓库或 Site 工作目录。可重复指定 `--evidence /path/to/check.png` 加入具名验证文件。拒绝 Git/环境元数据、测试存档、密钥文件、越界路径和符号链接；已有输出不会被覆盖。运行 `python3 godot-prototype/tests/test_package_delivery.py` 验证这些边界。

## 章柜版本的存档迁移

章柜采用v3存档。新版默认先读 `user://town-prototype-v3.json`；仅该文件不存在时才读取原 `user://town-prototype-v1.json`（内部版本v1或v2），后续保存写入独立v3文件。原文件保持原字节，可用于回退旧版。

v3文件是否存在就是一次迁入标记。已有v3即优先使用，损坏时保留文件并停止写入，不静默回退或再次覆盖迁移。首次写入失败不会创建完成标记，也不会改旧文件。

回退旧版只能看到升级前旧文件中的进度；之后在旧版新做的变化不会自动合并进已存在的v3。两份文件都保留，切回新版继续读取v3。请保留两份备份，不清理网站存储。图片导入/全量跨版本合并仍未接入。

这里的原型v3与原Vue/Web应用的v3是不同结构，尚不支持两者互相导入。
