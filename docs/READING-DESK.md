# 书屋阅读桌与模型细化

2026-09-28，第二十一切片。

## 阅读桌

街角书屋增加自己的阅读桌，不要求先修完书屋。一次有一本正在读的书；书名必填，可填写作者、书签位置、下次起点和关联阅读旅程。书签位置允许页码或章节文字，适用于纸书与电子书。可以持续追加摘记，摘记保留写下当天的日期和当时的书签位置，之后更新书签不会改写旧摘记。

可以标记读完或先放回书架，记录均保留，再打开下一本书。书架没有正在读的书时可以继续旧书；重读取消当前读完标记，保留所有摘记。当前书的信息可修改，历史摘记本轮只追加和查看，不提供删除。书架与成长手记互相连接。

关联使用现有 read-s1/read-s2/read-s3 声明。未接取时可从阅读桌打开出发手册、按原规则接下任务；已接取时直接回岩壁记录阅读。书签、摘记、读完标记不替代任务打卡或完成，不改变 XP、光、微光、三个任务名额或书屋修复资格。

## 保存边界

v3 home.reading 为可选扩展，默认空书架。包含 books，每本保留 id/title/author/bookmark/next/qid/started/finished/status/notes；阅读逻辑在 game/reading.js，store.js 只提供日期、ID 与响应式写入门面。读取和 JSON 导入共用 normalizeReading，旧存档与既有任务记录保持兼容，未知字段不进入状态。对书名、作者、书签、下次起点、摘记分别限制 80/60/80/160/1500 字；不按书本或摘记总数截断历史。

## 房屋与家具

保留柔和、程序建模的小屋风格。房屋和书屋使用实体山墙、双坡屋顶、分层瓦缝、檐口、屋脊；自家增加烟囱压顶、门板、窗旁百叶、窗台花箱和石砌基座。模型在地图和独立院落中复用。

家具重点细化床、沙发、书桌、书架，并补齐小凳、圆桌、植物、灯具、书堆、草席、圆毯和壁炉的局部构造。软垫采用更圆润的几何，床头柱与木条、书本封面与纸页、抽屉和桌面笔筒、陶盆卷边和叶片、灯罩边圈等均为几何细节。集市缩略图与室内摆放沿用同一个 furnitureModel；不新增贴图、外部资产和依赖，不改变价格、占格与回收规则。新增几何仍纳入现有静态合并与卸载释放。
