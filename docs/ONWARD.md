# 完成之后，下一件（第三十八切片）

> 2026-10-04 ｜ 完成弹窗 · 地图便笺

## 为什么

完成仪式原来只在成长线有下一阶段时给出接续。多数任务不属于成长线，完成后回到地图，便笺按「方向不限」从全部入门任务里随机推荐，与刚做完的事没有关系。刚做完一件事，正是最容易接上下一件的时刻；但仪式也不能变成催促。

## 是什么

- 完成结果页底部给**一个**「下一件」，从不自动接取。顺序：成长线下一阶段 → 手里还有的事（只提一句，不给按钮）→ 同方向的入门任务（复用地图推荐）→ 同方向的出发手册准备动作（复用第三十六切片，可写成自己的事）。卡片下方写「不急。今天到这里，也已经很好。」
- 方向来自刚完成的任务：在哪个行动小册方向里就用哪个；自建任务按领域对应（头脑→给头脑留点时间，等等）。
- 收好回到地图时，如果手里已经清空，地图便笺沿用这个方向，与完成页给出的是同一件（同一天同一个种子）。
- 主按钮仍是「收好了，回到地图」，集市与书屋链接不变。

## 规则位置

`game/onward.js`：`trailOfTask`、`onwardSuggestion`（只读，复用 `recommendMapTask` 与 `pickPrepMove`）。`CompleteModal` 新增 `direction`／`write` 事件，App 只在手里为空时改地图方向。没有新增经济通道、存档字段或内容。
