# 完成仪式的结束动线

2026-09-21。现有 CompleteModal 在任务已结算后，以购物为唯一主按钮，“先把这一刻记下来”又暗示记录尚未保存。这把真实行动的结束变成产品里的下一项待办。

本切片让“收好了，回到地图”成为唯一主按钮；明确完成记录已记入成长手记，无须购物或接下一步才能保存。购物与符合既有资格的成长线继续保留为次要动作。关闭与 Escape 只结束弹窗，不重复结算。保存失败时在弹窗内显示真实警告，不声称已持久保存。

仅改变完成后的表达和导航，不改变任务、奖励、微光、成长线资格、存档格式和小芽。主按钮返回地图并给键盘焦点一个可见落点；确认完成后的焦点移到结束按钮。

验收：npm test、build；1280 与 375px 验证结束回地图、重载仍保有一条记录及原奖励、购物与成长线可选、Escape 不重发奖励、保存失败提示、无横向溢出；桌面与手机日夜截图亲自核对。回退为还原本切片提交，不涉及迁移。
