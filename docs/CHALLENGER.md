## 参考与取舍

查阅 [明日方舟官方初次危机合约公告](https://ak.hypergryph.com/news/2019114303)、[寻昼行动资料与蚀刻章条件](https://wiki.biligame.com/arknights/危机合约第8赛季「寻昼行动」)、[PRTS 危机合约](https://prts.wiki/w/危机合约)。官方确认可自由搭配合约、常驻与轮换关卡、可任意多次尝试；资料站记录等级挑战和蚀刻章条件。机制启发是自选困难、明确条件、可重试、用荣誉记录突破。这是本项目的设计推论，不声称复现原作设计团队意图。

旷野采用六项完整的现实挑战，每项基础条件已经需要投入或勇气，另有三项可叠加条件。挑战等级是本专辑的条件权重，不能比较不同人的能力。常驻开放、无排行榜、无截止日期、无绝版、无失败处罚；不移植商店或新货币。黑色工业画面、警戒橙与原创金属几何章、切入和刻印反馈；不使用明日方舟图像、音乐、标志或文案。

## 行为契约

- 地图 → 任务岩壁 → 挑战者；独立 hash 页可直接预览，顶栏仍只有地图返回。专辑内一览、蚀刻章、档案是局部视图。
- 先查看真实条件、选择加码，再明确接取。共用三个任务名额。同一项目只能有一份进行中的尝试。
- 按既有自建任务保存一个不可编辑的挑战快照（版本、项目身份、基础条件、加码条件与权重）；从 accept / complete / abandon 结算。没有独立完成状态和奖励账本。普通任务和旧系列不改。
- 完成要求逐项确认原条件并写一句实际结果，game/store 层再次校验。岩壁、地图和专辑必须使用同一完成规则。挑战内容不可用“修改自己的事”降低要求。
- 暂放保留历史，可重新选择条件挑战。每次尝试有独立 task id；历史条件不随内容声明改动。完成一次只记录一次，不发 XP 或任务光，沿用原每天一份微光。
- 四枚原创章从有效 done + 冻结挑战快照派生：首次完成；最高等级 ≥8；三种项目完成；最高等级 12。零进度不得显示已获得。展示条件、真实进度、档案、原回顾；不得靠点“领取”造章。
- v3 可选字段沿 normalizePersonalTasks / normalizeState / parseImport 清洗。旧档无字段即原行为；未知版本、坏结构拒绝，不能静默抹去挑战。保留旧键，无不可逆迁移。
- 本轮内容标记 pending-review，作为用户明确要求的 GitHub Pages 预览专辑可用。此次预览授权不将其他待审内容一并放进构建；不存在商品发布。
