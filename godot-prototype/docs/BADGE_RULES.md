## 本轮流程与界面

作品集内一条轻入口「蚀刻章柜」，小家已有书架也可打开。世界HUD不增加新按钮。章柜上方先列当前尝试，下方两列图片/名称/状态；点章看条件。未接入的章保留条件和状态，不显示领取。

1. 在小说章或「实地求证」详情读目标，选择可选加码，确认接取后冻结完整条件、等级与日期。接取时可还没有关联作品。
2. 在尝试页单独选择证据：现有文字作品，以及实地求证的已收好观察。保存证据选择，或关闭取消本次选择。关联对象可在完成前更换，冻结目标不可修改。
3. 完成前显示辅助证据计数，并要求填写非空结果自述、逐项确认原目标与所选条款。小说不自设字数门槛；关联作品允许节选或完成记录，不能把12000字编辑器当成整本小说容量。
4. 最后一次确认生成不可变完成记录：冻结作品与观察内容、自述、确认项目和日期。章从这些有效记录推导；界面只用克制状态提示和章详情，不额外挡住世界。
5. 进行中可暂放/恢复，不扣款、不设期限。与创作共用最多3个进行名额；模型层同时约束两个入口，防止分别点击绕过上限。

## 规则核对与边界

- 原 `challengeHonors` 用全部契约完成记录计数，因此实地求证仅完成基础4级目标也能获得越界者。额外条款提高等级，达到8级才得淬火意志；本轮最高10级，不能解锁临界之上。只有一种行动，不解锁多面锋芒。
- 同一次完成重复点击不重复写记录或发微光。小说已刻印后详情显示原完成记录；不靠重新点接取发同一章。实地求证重复尝试必须关联新的完成作品，避免复用同一结论重复记功。
- 开始/绑定/暂放/恢复/完成各步明确保存；关闭尚未确认的表单不更改模型。结果编辑草稿暂留会话，保存失败遵循现有「未保存/重试」机制，重试只写盘不再颁奖。重开读旧文件仍是旧状态，不谎称已持久保存。
- 老存档v1/v2首次读取时补空章柜，随后写入独立v3文件；保留升级前旧文件，回退旧版可读升级前进度，新章记录仍留给新版。已有v3优先，损坏v3不静默回退。家具、记录、作品、每日账本均保留。非法/未知章数据整份拒读，保留原文件；不单独持久化可篡改的earned标志。
- 条件以版本化规则冻结，后续定义修订必须保留既有规则版本读取。历史证据不随原作品/观察编辑而变。

## 最小闭环
章柜查看 → 接取小说/实地求证（冻结目标与可选加码）→ 关联现有文字作品（可为节选或完成记录） → 真实完成并保存作品 → 逐项确认＋结果自述 → 推导章的状态 → 重开后保留。可暂放，不扣款，没有期限。

与创作共用最多3个进行名额。个人挑战不另给XP，完成只共享既有每天一次5微光。重复点完成、购买家具、重复打开章柜均不能重复授章或加钱。

实地求证使用已收好的观察和一件已完成的文字作品作为辅助证据：至少12条已收好的观察、3个不同地点、正文至少600非空白字；实际观察/访谈/重访是否做过仍由本人逐项确认。原main依赖自述，不会自动验证现实行为；本轮额外本地门槛不冒充外部认证。小说不擅设字数标准，但普通短文不能因保存动作自动被标成写完小说。

全部完成条件、结果自述和所选证据均冻结保存。之后修改原观察/作品不改历史。章状态由有效完成记录计算，不保存可被独立篡改的earned布尔值。
