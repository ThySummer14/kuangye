# 家具里的生活记忆

2026-09-29，第二十四切片。

小家中点选已摆放的家具，或从「全部家具」选择它，场景下方会展开记忆卡，手机会将卡片滚动到可见区域。卡片使用现有 inventory.memory 的任务 ID、日期和回顾；没有铭牌的物件只说明它是一件喜欢的家具或成长礼物，不编造经历。卡片可以收起或进入摆放编辑，不改变原来的互动、收回与回收入口。

「翻到那一天的手记」进入成长手记中的原记录。先按 qid + 日期定位；旧铭牌日期缺失或不同且该 qid 只有一条记录时，可定位唯一记录；同一任务有多条且日期不匹配时不猜测。找不到原记录时保留铭牌并给出说明。匹配由 game/journal.js 的只读函数负责。

手记会切回完成记录、清理筛选、展开目标所在的分页、滚动并将键盘焦点交给目标文章。文章用浅色纸张突出，说明由哪件家具翻来；「回到这件家具」返回小家并重新选中该物件。正常从地图打开手记不带上一次的目标。导航状态只在当前会话里传递，刷新后仍按正常场所打开。

不新增存档字段，不修改铭牌归属、回顾、家具、任务记录或奖励。自建任务标题继续由既有 taskById 解析。回收后的家具不再有室内入口，原完成手记仍按既有规则保存。

验收：67 项测试和构建通过；1280/375 验证位于第 16 条的旧记录定位、分页展开、焦点、返回家具、普通手记入口不残留目标、翻阅前后 home 完全不变，无 pageerror/横向溢出。另直接点击 3D 工作台并进入目标手记验证拾取主路径。证据 output/furniture-memory-validation.txt、furniture-memory-final-build.txt、output/playwright/furniture-memory-*；脚本 scripts/qa-furniture-memory.js 使用 5193 本地独立 ?qa 存档。
