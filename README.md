# 旷野 · 小芽的家

完成生活里的小事，收集一点光，为小芽布置一个温暖的小家。

旷野 v3 把原有的人生支线任务接进一个可探索的 3D 小岛：任务岩壁、林间集市、小芽的家、院子、街角书屋等八个场所。家具不只是奖励，第一次完成任务后的首次购买会把那段回顾记在家具铭牌上。

## 可以做什么

- 地图上的小小画室可以开始自己的作品，带回正文与最多四张本地图片，收好后进入作品集，陈列／收回小家的纸面画框，从成长手记回望，并导出 PNG 卡片或完整 HTML 作品集。三个主题十二次原创练习在本地 DEV 可试用，待审内容不进入正式构建。任务共用三个名额，不另发任务光或 XP；放下时作品仍在，继续保留原任务历史。见 [画室作品集](docs/PORTFOLIO.md)。
- 书屋的街角来访连接居民故事与真实创作：接下约定、在画室带回成果、明确交回，书屋和地图留下纸牌陈列，成长手记保存来往。第一位居民阿禾与明信片委托为本地待审草稿；已接取故事随备份保留，正式构建仍能继续。见 [街角居民](docs/RESIDENTS.md)。
- 院子的观察册保存地点、日期与一个具体发现，可带两张本地图片；草稿自动保存，收好后可检索、分类、修订，从成长手记回到原页。记录不占任务名额、不自动完成任务或发奖励，画室与观察册共用图片容量。三个观察起点仅在 DEV 试用，正式构建可以自由记录。见 [院子观察册](docs/OBSERVATIONS.md)。
- 收好的观察可以主动带到画室：先看素材、选择是否带图，写下作品名与完成条件，再接下创作。素材保存当时的快照，成果从空白开始；原观察与作品双向返回，同一页始终回到同一件作品。素材图计入共用容量，导出作品只包含成果，完整 JSON 保留素材与关联。见 [从观察到作品](docs/OBSERVATION-CRAFT.md)。

- 家门前有一块可布置的院落：六件免费材料支持摆放、旋转、移动、收回；新增三种布局方案，可先试摆、确认采用或取消，采用后仍能逐件调整；墙面、屋顶、门、门廊与小径可搭配，直接同步到大地图。 模型包含木条长椅、分枝枫树、褶皱晾衣与石沿鸟盆，见 [院落模型细化](docs/YARD-MODELS.md)。
- 小家、书屋、画室与木器铺有错缝瓦顶、厚窗框、石基与各自的木作细节；搭配房屋自动拉近，书屋也能近看修复阶段。见 [房屋建筑细化](docs/BUILDING-MODELS.md)。
- 在书屋记下正在读的一本书、书签和下次起点，追加带日期与位置的摘记；读完或暂放后留在书架，可从成长手记回望。记录不自动打卡或发奖励。见 [阅读桌与模型细化](docs/READING-DESK.md)。
- 在书屋的[问号夹页](docs/INQUIRY-DESK.md)里追一个具体问题：留最初的猜测、带来处的线索、自己的解释和下一步。可以收好旧页再翻回来，也能把下一步带到岩壁写成自己的事；记录与备份一起保存，不自动推进任务或发奖励。
- 街角书屋随既有阅读成长线分三次修复：打开门窗、安好书架、点亮灯。过去完成的阅读也有效，修复免费、不额外发奖励，阅读回顾留在街角。见 [第一条街规则](docs/TOWN-FIRST-STREET.md)。

- 拖动、缩放 3D 小岛，点建筑或场所标签进入；桌面与手机都从地图进入，子页可以轻量返回地图。
- 界面采用暖纸「旷野手账」：薄顶栏与线描路牌，手机先看到今天的行动，再选择场所。地图可按方向与 15／30 分钟找到起步任务，同一天稳定推荐、可主动换一件；手里已有任务时优先自己的安排。短时没有合适内容会如实留白。见 [旷野手账与第一次出发](docs/FIELD-JOURNAL.md)。
- 在任务岩壁“自己写一件”：写明目标和完成条件，可安排第一步、修改进行中的内容，完成后进入手记并可绑定家具铭牌。自建任务共用 3 个名额，不另发 XP/任务光，沿用每天一次的微光；内容与备份一起保存，见 [自建任务规则](docs/PERSONAL-TASKS.md)。
- 今日入口精选五领域各一件低门槛任务；完整任务库、搜索、成长线、按天记录和累积记录继续保留。同时最多接 3 件事。
- 普通模式的任务岩壁有五本[行动小册](docs/ACTION-NOTEBOOKS.md)：十五种生活情境组织 29 件原有任务，每次只给两件候选，展示第一步；可以继续原任务，也可沿着情境写自己的事。头脑小册可接到书屋，显示手里这本书的书签或正在追问的下一步。
- 出发手册为 42 件原有任务提供专属准备与步骤，其中 32 件有 56 条情境起步提示；卡住时展开一条，已接任务可把这一步写进便笺。准备动作不替代原来的完成条件。
- 接下任务后写一张出发便笺：选开始时机、写自己的第一步。地图能查看与切换手里的安排，并直接回到对应任务；便笺随本地存档和 JSON 备份保留，可随时修改或清除。
- 集市商品可打开「近看与尺寸」：旋转模型、查看日夜与占地格，购买后回家布置。尺寸与价格沿用同一份家具声明。
- 完成任务收获光；在四个摊位选择 20 件可购买家具。另有 Lv.3 / 5 / 7 / 9 的 4 件成长赠礼。
- 从第一天就拥有一间 3 × 3 米的小屋，可花光向两个方向逐次扩建，最大 6 × 6 米。以 0.5 米网格摆放家具，支持 90° 旋转、移动、收回背包和按实付价格 70% 回收。实体家具不能重叠，地毯可以垫在家具下面。
- 直接点击 3D 地面放置，也可用平面格子与键盘操作。方向键选择格子，R 旋转，Esc 取消当前布置。
- 小芽采用 [定稿形象规范](docs/mascot.md) 的奶油白团子、左高右矮软角、双叶芽与琥珀金实心眼，有14种情绪，表情采用保留速度的阻尼弹簧插值，包含眨眼、呼吸、视线跟随与摸摸互动；3D 小芽也使用同一套表情参数。
- 点选家中的家具可展开记忆卡，翻到铭牌对应的旧手记，再回到原家具；没有铭牌时不编造回忆。见 [家具记忆](docs/FURNITURE-MEMORIES.md)。
- 小芽的本子记录完成回顾和暂时放下的任务；查看五维属性、累计生活记录，导出成长报告与 JSON 备份。

完成仪式以“收好了，回到地图”结束。记录在确认完成时保存；购物和接下成长线均为可选动作，保存失败会在弹窗内提示。

## 光与记忆

任务结算奖励为 `round(xp × 0.6 / 5) × 5`，对应 E–S 难度获得 5 / 15 / 30 / 60 / 120 / 300 光。草席定价 5 光，第一件 E 级任务即可换到。

按天任务（原「连续 N 天」）数的是记录过的不同日子：记满目标天数即可完成，空档不清零，最长一口气只作欣赏。昨天做了忘记记，可以诚实补记一笔，不消耗任何东西；地图便笺上可以直接「今天做到了，记一笔」。完成时回望这些日子散落在多长的时间里。见 [节奏](docs/RHYTHM.md)。

每个有记录的日期只记一次微光，累计七个日期再获得 5 光。日期不必连续，中断不会清空。打卡、有效数量记录、补记和完成会登记日期；放弃不扣光、不奖励光。

每条完成记录最多绑定一次新购物品的铭牌。回收家具不会删除任务手记，赠礼不能回收或购买。旧货摊的三件旧物七折售卖，顺序由日期和赛季种子确定，没有倒计时或绝版压力。

## 保存与迁移

游戏数据保存在当前浏览器 `localStorage` 的 `kuangye.v3`，无业务后端、无游戏账号、无云同步。Sites 的站点访问控制独立于游戏存档。

第一次打开会读取 v3；损坏时依次尝试 `kuangye.v2` 与 `kuangye.v1`。旧版键保留不覆盖，历史已完成任务会折算为起始光余额。导入 v1/v2/v3 JSON 统一经过白名单清洗；当前任务、小家库存、摆放位置、铭牌、阅读书架、问号夹页、作品集、观察册（含压缩图片）与街角来往一起导出。恢复备份前，界面会确认替换，并先自动导出当前数据。

**不同网址不能直接读取彼此的浏览器存档。** 从旧 GitHub Pages 迁移到 Sites 时，先在旧网站导出，再在新网站的「成长手记 → 导入备份」恢复。导入会拒绝当前任务库无法识别的历史记录与高于 v3 的未来版本，保留原备份，不静默丢失；无痕浏览、清理浏览器数据或换设备前也应备份。

本地 `?qa` 独立试用存档另有 39 件待审短任务，含 [户外探索](docs/OUTDOOR-NOTES.md)、[生活小册](docs/LIFE-NOTES.md)、[创作小册](docs/CREATIVE-NOTES.md) 与 [相处小册](docs/CONNECTION-NOTES.md)。它们不进入普通模式或正式任务池。生活、创作与相处的试用场景共用 `SituationFieldNotes.vue`；普通行动小册使用 `TrailNotebook.vue`，任务规则仍由 store/game 层负责。

## 开发与检查

运行时依赖仍只有 Vue 3 与 three.js；无外部模型或贴图。场所与缩略图按需加载，任务入口不加载 three；分包边界与验证见 [场景加载](docs/SCENE-LOADING-AND-PREVIEW.md)。家具图来自同一套 3D 模型的本地渲染。

```bash
npm --prefix app ci
npm run dev        # Vite 开发服务器
npm test           # node:test，逻辑、存档与场景回归检查
npm run build      # 构建 app/dist，再生成 Sites 使用的根 dist
```

根 `.openai/hosting.json` 保存 Sites 绑定，`static.directory` 为 `dist`。发布使用构建后的静态产物。GitHub Pages 工作流仍在 `.github/workflows/`，本次发布同步推送到 GitHub；推送 main 也会触发现有 GitHub Pages 工作流。

## 小家生活更新（2026-09-13）

当时采用绿色种子与双叶轮廓；当前外观以 [形象规范](docs/mascot.md) 与六张参考图为准。小芽安静站立，点击角色可摸摸；选择家具后可浇花、坐下、打盹、读书或随收音机摇摆。发现会保存在成长手记，重复互动不产生货币。

房间可拖动旋转及调整俯视高度，支持滚轮／双指缩放和按钮控制。上半墙与窗帘、灯串、画框作为同一个剖切组随视角淡出，避免墙饰浮空；自由摆放的挂毯增加落地木架。四种墙色、三种地板和三种光线免费切换。

扩建从 30 光起，每次提高 20 光；每次沿选中方向增加一米，家具保留网格坐标。`game/room.js` 管理扩建与装饰存档，`game/buddy-walk.js` 管理可行走区域与路径，`scenes/home-life.js` 将路径、互动和支撑面阴影接到角色。

## 装修师傅与窗外天气

从地图进入「木器铺」，找木木师傅办理扩建、换墙面和地板。天气默认通过浏览器授权获取设备附近位置，坐标取两位小数用于 Open-Meteo 查询；拒绝、超时或不支持定位时回退新乡。定位仅在内存中使用，不写入存档。网络失败会显示同步失败，并保留上次数据或明确标注临时晴天。

时间默认按 UTC+8 每半分钟更新，光照随时间变化；支持自选晴、云、风、雨、雪、霜、月夜及日间、日落、夜间光线。室外模型天气每半小时刷新，不是设备自带的气象传感器读数。天气与手动偏好随 v3 存档保存。

小芽取消身体深度压缩；朝向采用最短角度过渡，动作使用当前姿态连续追随。眨眼和嘴形连续变化。设计参考 moodstone 与 bloub 的分层姿态、非对称眼形和眨眼节奏，未复制项目资产。

## 2026-09-14 执行批与交接

## 第二轮 · 暖白软角（2026-09-19）

本节为第二轮历史记录；当前外观已按 [形象规范](docs/mascot.md) 实施，深色眼睛已替换为琥珀金。四方向概念与保留 idea 见 [设计档案](docs/ideas/mascot-directions.md)。当时选择02：两个不等高的圆钝短角、饱满闭合身体、小型深色五官和浅桃色脸颊。身体调为暖白，减少褐色阴影；用少量环境补亮保留夜间体积，不能把形象拉成扁片。

地图「小小画室」进入独立表情试验台，可以查看14种情绪、任意两种过渡、暂停与循环、调节速度/阻尼，切换平面和可拖动旋转的立体预览；返回地图仅需一击。试验台不加载游戏 store。主站 BuddyFace 与3D角色共用情绪、面部轮廓与暖白配置。

`game/mascot.js` 管外观与闭合轮廓，`game/emotions.js` 是情绪参数的单一来源；赛季皮肤不拥有情绪或互动状态。目前只有已选02默认皮肤，没有新增换肤商城。3D身体、五官和柔和接触阴影均为程序化几何，没有角色贴图；bloub 两个几何辅助函数保留 MIT 许可，moodstone 和 momo 仅作节奏/体积参考。
