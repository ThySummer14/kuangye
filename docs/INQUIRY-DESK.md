# 头脑小册与问号夹页

2026-10-03，第三十二切片。普通模式可用。地图 → 任务岩壁 → 给头脑留点时间；地图 → 街角书屋 → 问号夹页，均在两击内。

把“想学些什么”的大方向缩成一个可以真正去读、去问或动手确认的问题。夹页用于带回行动中找到的东西，让下一次知道从哪里继续；不会生成答案，也不把写笔记视为完成原任务。

头脑小册有三种情境，每次只给两件原有任务：读不进去对应三天阅读与整本书短评；想弄懂一点对应研究综述与实际演示；想把学的留下对应十首诗与五百个新词。五件原任务新增准备、三步行动、专属回顾和十条起步办法。读完整本与二百字短评、三千字综述并讲给外行、实际演示、背诵十首和三十天五百新词等要求均保留。没有新增有奖任务，正式任务池与待审内容数量不变。

## 一张夹页的使用

先写自己的具体问题，可以补最初的猜测和一个起步动作。一次手里只留一个正在追的问题。做过之后，追加带日期、来源的线索，再写自己当前能解释到哪里，还有哪里不确定。原先的猜测与现在的解释一起呈现，避免只留下一个最终答案。

线索来源是用户自己填写的书名页码、网页地址、观察地点或实际尝试方式；未写来源时明确显示缺省状态。文字没有预填，没有自动检索或来源真实性认证。页面可“先夹好”，之后从历史列表翻回来继续；收好不要求已经找到答案，也不删除任何已有线索。

有下一步时可以带到岩壁：第一步预填自己的原文，头脑领域预选，目标和可判定的完成条件留空，由用户完成。没有直接创建或自动接取；仍受原有三个任务名额限制。夹页的下一步与任务第一步均限 160 字，避免转写时截断。

小册展示正在读的书名、真实书签与下次起点，或当前问题与下一步。书屋接任务或继续阅读时，返回岩壁会选中头脑小册并聚焦准确的进行中卡片。地图仍是唯一主入口，顶部只保留回地图。

夹页转写建议只在这次进入时使用。表单关闭或保存后，浏览器返回岩壁不会重新弹出同一张表单。

## 保存与边界

`game/inquiry.js` 管问题、线索、收好与继续；`store.js` 提供响应式门面；`InquiryDesk.vue` 负责展示与输入。`home.inquiry.pages` 是可选 v3 字段，旧 v1/v2/v3 档没有它时得到空夹页，旧键保留，共用 `normalizeHome` 的导入／加载清洗路径。所有有效历史页面和线索数量均保留，内容缺失或身份重复会拒绝整份导入，不悄悄删掉条目。记录随既有 JSON 备份保存。

操作不会调用打卡、记录数量、完成或微光发放。原任务仍在岩壁按既有要求确认；没有奖励通道、依赖或远端服务。书屋切换阅读桌与夹页会卸载对应输入界面，未保存的输入不会跨页面恢复；保存过的内容会保留。当前解释可修改，暂不保留每版解释的修订时间线。
