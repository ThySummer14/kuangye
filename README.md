# 旷野 · 小芽的家

完成生活里的小事，收集一点光，为小芽布置一个温暖的小家。

旷野 v3 把原有的人生支线任务接进一个可探索的 3D 小岛：任务岩壁、林间集市、小芽的家和瞭望台。家具不只是奖励，第一次完成任务后的首次购买会把那段回顾记在家具铭牌上。

## 可以做什么

- 拖动、缩放 3D 小岛，点建筑或场所标签进入；手机也可通过底部导航直达。
- 今日入口精选五领域各一件低门槛任务；完整任务库、搜索、成长线、连续打卡和累积记录继续保留。同时最多接 3 件事。
- 完成任务收获光；在四个摊位选择 20 件可购买家具。另有 Lv.3 / 5 / 7 / 9 的 4 件成长赠礼。
- 从第一天就拥有一间 3 × 3 米的小屋，可花光向两个方向逐次扩建，最大 6 × 6 米。以 0.5 米网格摆放家具，支持 90° 旋转、移动、收回背包和按实付价格 70% 回收。实体家具不能重叠，地毯可以垫在家具下面。
- 直接点击 3D 地面放置，也可用平面格子与键盘操作。方向键选择格子，R 旋转，Esc 取消当前布置。
- 小芽有 10 种情绪和接取任务时的期待状态，表情采用临界阻尼插值，包含眨眼、呼吸、视线跟随与摸摸互动；3D 小芽也使用同一套表情参数。
- 小芽的本子记录完成回顾和暂时放下的任务；查看五维属性、累计生活记录，导出成长报告与 JSON 备份。

## 光与记忆

任务结算奖励为 `round(xp × 0.6 / 5) × 5`，对应 E–S 难度获得 5 / 15 / 30 / 60 / 120 / 300 光。草席定价 5 光，第一件 E 级任务即可换到。

每个有记录的日期只记一次微光，累计七个日期再获得 5 光。日期不必连续，中断不会清空。打卡、有效数量记录、补记和完成会登记日期；放弃不扣光、不奖励光。

每条完成记录最多绑定一次新购物品的铭牌。回收家具不会删除任务手记，赠礼不能回收或购买。旧货摊的三件旧物七折售卖，顺序由日期和赛季种子确定，没有倒计时或绝版压力。

## 保存与迁移

游戏数据保存在当前浏览器 `localStorage` 的 `kuangye.v3`，无业务后端、无游戏账号、无云同步。Sites 的站点访问控制独立于游戏存档。

第一次打开会读取 v3；损坏时依次尝试 `kuangye.v2` 与 `kuangye.v1`。旧版键保留不覆盖，历史已完成任务会折算为起始光余额。导入 v1/v2/v3 JSON 统一经过白名单清洗；当前任务、小家库存、摆放位置与铭牌一起导出。恢复备份前，界面会确认替换，并先自动导出当前数据。

**不同网址不能直接读取彼此的浏览器存档。** 从旧 GitHub Pages 迁移到 Sites 时，先在旧网站导出，再在新网站的「成长手记 → 导入备份」恢复。无痕浏览、清理浏览器数据或换设备前也应备份。

## 开发与检查

运行时依赖仍只有 Vue 3 与 three.js；无外部模型或贴图。家具图来自同一套 3D 模型的本地渲染。

```bash
npm --prefix app ci
npm run dev        # Vite 开发服务器
npm test           # node:test，22 项逻辑、存档与场景回归检查
npm run build      # 构建 app/dist，再生成 Sites 使用的根 dist
```

根 `.openai/hosting.json` 保存 Sites 绑定，`static.directory` 为 `dist`。发布使用构建后的静态产物。GitHub Pages 工作流仍在 `.github/workflows/`，本次发布同步推送到 GitHub；推送 main 也会触发现有 GitHub Pages 工作流。

## 项目地图

| 位置 | 职责 |
| --- | --- |
| `app/src/App.vue` | 场所导航、hash 历史、公共弹窗、页面编排 |
| `app/src/store.js` | 兼容原 API 的响应式状态与任务操作门面 |
| `app/src/game/home.js` | 光结算、微光、购买、铭牌、回收与赠礼 |
| `app/src/game/placement.js` | 网格边界、旋转占地和碰撞检查 |
| `app/src/game/save.js` | 旧存档规范化、字段清洗 |
| `app/src/game/emotions.js` | 情绪参数与稳定弹簧步进 |
| `app/src/game/webmcp.js` | 可选的页面进度读取与导航工具 |
| `app/src/data/` | 任务、家具与赛季声明 |
| `app/src/scenes/` | three.js 场景、家具模型、缩略图与 GPU 资源管理 |
| `app/src/components/*View.vue` | 任务、商店、小屋与手记工作界面 |
| `app/src/world.css` | v3 主题与响应式界面；旧 `style.css` 为基础及成长线提供样式 |
| `app/test/` | 经济、碰撞、表情、迁移及 store 集成检查 |

旧版未使用的界面组件保留在源码中，不再挂载进主要场所导航，便于比较历史实现。后续可按独立清理任务移除。

## 小家生活更新（2026-09-13）

小芽恢复绿色种子、浅色肚皮和双叶轮廓，3D 使用曲面身体和贴合曲面的表情。点击地面会寻路蹦跳，点击角色可摸摸；选择家具后可浇花、坐下、打盹、读书或随收音机摇摆。发现会保存在成长手记，重复互动不产生货币。

房间可拖动旋转及调整俯视高度，支持滚轮／双指缩放和按钮控制。上半墙与窗帘、灯串、画框作为同一个剖切组随视角淡出，避免墙饰浮空；自由摆放的挂毯增加落地木架。四种墙色、三种地板和三种光线免费切换。

扩建从 30 光起，每次提高 20 光；每次沿选中方向增加一米，家具保留网格坐标。`game/room.js` 管理扩建与装饰存档，`game/buddy-walk.js` 管理可行走区域与路径，`scenes/home-life.js` 将路径、互动和支撑面阴影接到角色。
