## 二、各族写作卡

### 01 四时归灯 · 限时 `seasonal`

```text
familyId: lantern-seasons；seriesId: ser-lantern-seasons；revision: 1；badgeId: badge-lantern-seasons
主题名：四季晚灯
为什么是有限事件系列：每个季节是一个天然的"有限窗口"，错过下季有新变体，同一盏灯不绝版
长期成长方向：四个季节各点亮一盏，把"照顾自己"变成一年四季的习惯底子
领域：live；赛季：seasonId s1，variantId s1-autumn
```

**m1（素刻）：独立做一顿完整的晚饭**（任务 `lt-s1-dinner`，canonicalGoalId `goal-dinner-from-scratch`）
- 判定句：同一顿饭里完成 买菜或取食材 → 做出至少一荤一素一主食 → 收拾干净厨房，三段都真实发生才算；可重复做饭，但本目标只计第一次从零到收拾完毕的完整闭环。
- cat live / diff D / type once。证据自述：回顾里写这顿饭最手忙脚乱的一步。
- 不能重复计数：换菜单重做不算新目标；点外卖半成品不算"做"。
- m2–m6 方向（后季变体）：冬令进补汤锅、年节家宴一道硬菜、给别人做一顿……文案后季写。
- 章象征：灯——不是进度条，是每个季节桌上亮起的那盏。NPC 缘由：小芽说"天冷了，桌上有一盏灯，就有热饭"。图鉴摘要：四季晚灯——每一季，学会一件照顾自己的小手艺。

### 02 山径成桥 · 阶段 `staged`

```text
familyId: path-bridge；seriesId: ser-path-bridge；revision: 1；badgeId: badge-path-bridge
新链声明：chainId "hike"（stage 1→2→3，前置即 stage 顺序）
主题名：从门口到山里
为什么是阶段：徒步的能力阶梯真实存在——近郊步道、整座山、过夜重装，差的是体能和经验
长期成长方向：从半日近郊到能把家背上山
领域：body
```

| 任务 | 阶段 | 判定句 | diff |
|---|---|---|---|
| `hk-s1` 第一次近郊步道半日徒步（goal `goal-first-day-hike`） | m1 | 步行为主的步道连续走 ≥3 小时（含休息），当天往返；回顾写一处路上记住的风景 | D |
| `hk-s2` 完整山径往返 ≥8 公里（goal `goal-full-mountain-loop`） | m2 | 一条有明确山顶或垭口的山径，往返 ≥8km、累计爬升 ≥400m；运动记录或地图截图仅为自证，不上传 | C |
| `hk-s3` 山里过一夜（goal `goal-overnight-in-hills`） | m3 | 背包在山间住一晚（露营/山居皆可），自己背主要装备；回顾写一件"下次会换一种带"的东西 | B |

- 不能重复计数：同一条路线第二次走不算新 goal（换路线才算 stage 内再练，不再发 XP）。
- 章象征：桥——山径一段段接起来，桥的另一头是更远的山。NPC 缘由：木木给行山的人做杖，"杖是现成的，路得你自己走"。图鉴摘要：从门口到山里——身体把你带到更远处。

### 03 门外初光 · 1st `first`

```text
familyId: door-first-light；seriesId: ser-door-first-light；revision: 1；badgeId: badge-door-first-light
firstKey（m1）: first-solo-trip
主题名：独自出发
为什么是 1st：人生第一次独自出门，是勇气域最诚实的一次"第一次"，且只有一次
长期成长方向：第一次之后，把出发变成可以重复的能力，再把能力传给别人
领域：courage
```

| 任务 | 节点 | 判定句 | diff |
|---|---|---|---|
| `df-s1` 第一次独自过夜旅行（goal `goal-first-solo-trip`，firstKey `first-solo-trip`） | m1 | 在不是家的城市或村落独自过 ≥1 夜，行程由自己决定；诚实自述为首次；回顾写一个只有独自才有的时刻 | A |
| `df-s2` 独自规划两日以上的深度行程（goal `goal-solo-deep-itinerary`） | m2 | ≥2 天、 ≥3 个自己规划的行程点（不含往返），完成后写一段"计划 vs 实际" | C |
| `df-s3` 带一个人完成ta的第一次（goal `goal-bring-first-timer`） | m3 | 以同行人第一次为标准（ta 诚实自述），你负责其中一段完整规划；不算ta的章，只算你的传递 | B |

- 章象征：门外初光——门推开的那一下，光是新的。NPC 缘由：小芽"第一次出门那天，我会在地图上看着你"。图鉴摘要：独自出发——第一次之后，门就一直开着。

### 04 滴水成湾 · 累计 `cumulative`

```text
familyId: drip-to-bay；seriesId: ser-drip-to-bay；revision: 1；badgeId: badge-drip-to-bay
METRICS 键：books（读过的书，单位"本"）
主题名：读过的书，都还在
为什么是累计：读书的成果天然按本数跨时间累积，且已有 done.units 真实结算数据可用
长期成长方向：从 3 本到一辈子的一湾
领域：mind
```

| 任务 | 节点 | 判定句 | diff |
|---|---|---|---|
| `db-s1` 读完并记录一本完整的书（goal `goal-record-one-book`，metric books mv 1） | m1 支撑事件 | 从头到尾读完一本（教材目录级翻阅不算），回顾写三句话以内"这本书讲了什么"；m1 门槛=**累计 books ≥3**，历史已结算的本数计入 | D |
| `db-s2` 一个自然月读完 3 本（goal `goal-three-books-month`，type total，target 3） | m2 | 同一自然月内完成 3 本并各自记录；月内重读同一本只计一次 | C |
| `db-s3` 啃完一本"硬书"（goal `goal-finish-hard-book`，metric books mv 1） | m3 | 一本你曾中途放弃过的书（回顾里说明当年卡在哪）或超 400 页的非虚构；m3 门槛=**累计 books ≥10** | B |

- 不能重复计数：同一本书只结算一次 books；m2 的月度目标与 m1 的累计分别取证据，同一本可同时推进两个目标（合同允许：不同目标不同维度），但月内重读不重复结算。
- 章象征：湾——一滴水不值得记，一湾水看得见。NPC 缘由：小芽"每本书都会流进同一个湾里，我帮你数着"。图鉴摘要：读过的书，都还在。

| 任务 | 组 | 判定句 | diff |
|---|---|---|---|

### 08 湖心回声 · 复盘 `reflection`

```text
familyId: lake-echo；seriesId: ser-lake-echo；revision: 1；badgeId: badge-lake-echo
来源范围：任意一条已完成任务记录或一段自述经历
主题名：给走过的路一个回声
为什么是复盘：已有 review 是完成时的一句感想，缺一次"有结构的回头看"；一次明确的复盘事件，不是日记
长期成长方向：从复盘一件事，到复盘一个阶段（后季）
领域：mind
```

**m1（素刻）：完成一次三问复盘**（任务 `le-s1`，canonicalGoalId `goal-three-question-review`）
- 判定句：选一段已完成的经历（引用 ≥1 条 done 记录或自述一段真实经历），写下三段：发生了什么 / 为什么会这样 / 下次遇到同类事怎么办。三段各 ≥1 句、合计 ≥80 字；不判情绪正负，不搞字数竞赛。
- cat mind / diff D / type once。不能重复计数：同一条来源记录对本 family 只计一次；后季想做"一年复盘"属于新 goal，不与 m1 重复。
- 章象征：回声——喊过的话在湖心回来一次，你才听清自己说了什么。NPC 缘由：小芽陪你坐在湖边，"我们不赶时间，从头讲给我听"。图鉴摘要：给走过的路一个回声。

## 三、跨族规则重申（实现时的硬约束，供评审确认）

1. 一族一章；m1=素刻，m1–m3=嵌纹，m4–m6=镀彩。首季发布清单：01 仅 m1；02/03/04/06/07 开放至 m3；05/08 仅 m1。文案不宣称未开放的阶位。
2. 一条现实成果一个 canonicalGoalId，不得拆成两个独立目标；primaryFamilyId 每任务唯一。
3. 无倒计时、无断签惩罚、无放弃扣款；05 的"7 天窗口 ≥5 顿"是窗口计数不是连击，断了就从下一个 7 天窗口重新数。
4. 03 的历史首次补录只入荣誉条目，不补 XP/光；已有经历换设备/换季不变成新"第一次"。
5. 所有证据均为诚实自述（回顾文本/勾选确认），无拍照上传、无定位、无社交认证——无后端的前提下这是唯一诚实的边界。

## 四、需要你裁决的点（不阻塞实现准备，但阻塞上线）

1. **主题方向**：八条线里有没有你不想见到的（比如独自旅行对你想面向的用户太具体/太贵）？哪条想换主题词？
2. **文案口吻**：目前按现有任务库的语气（"不用快，跑完就算"）写的判定句与回顾引导；NPC 缘由是否越界（小芽/木木只是陪伴者，不是审批者）。
3. **难度体感**：df-s1 定了 A（史诗，独自过夜旅行）；如果觉得首季 m1 就出现 A 太重，可降为"第一次独自看日出（C）"，过夜旅行移到 m2。
4. **05 的组合难度**：E+D 的组合是否太轻？可以把 ww-s1a 提为 C（学会两种主食）。
