## 2. 设定铁律（防伪特征，缺一即走形）

1. 圆顶团子身体，下宽上窄，**无腿**，常驻坐感轮廓。
2. 头顶两只圆钝软角，**左高右矮**，永远不对称。
3. 软角之间一棵嫩芽，**恰好两片叶**，带柔和自发光绿晕。
4. 眼睛为**实心琥珀金椭圆，无瞳孔、无高光**（渲染允许轻微自发光，禁止贴高光贴图）。
5. 嘴是小号「w」形；腮红是两块低饱和粉色椭圆，位置偏脸下方。
6. 手是体侧两个与身体同色的小圆瘤，**无手指**；拿东西靠"嵌进身体"作弊。
7. 一切道具（光罐、围巾、帽子）都是穿戴层，**不写进身体**，基础形象永远保持原样。

## 5. 技术路线：3D + 三渲二（不做 Live2D）

结论：小芽在 app 内继续走 three.js 3D 管线，用三渲二渲染出参考图的平涂观感。理由：

- 项目本体是 three.js（`app/src/scenes/`），3D 小芽已存在于小岛、房间与瞭望台，Live2D 会变成第二套 runtime 且进不了 3D 场景。
- Live2D 的优势（发丝摆动、脸部透视形变）对无四肢、无头发的团子完全不成立；团子的戏在压扁/拉长/融化，恰是 3D scale 动画的家常菜。
- 现有 14 情绪阻尼弹簧系统（`emotions.js`）保留，直接驱动新的表情参数。

实现要点：

1. **模型**：低模圆顶身体 + 两个不对称软角 + 两叶芽（总面数 <2k 足够）。
2. **身体材质**：`MeshToonMaterial` 或 `MeshBasicMaterial` + 极浅竖向渐变贴图；阴影压到最轻，参考图几乎没有明暗。
3. **眼睛**：纯色椭圆贴片（琥珀金 + 轻微 emissive），形状切换用贴图/几何 morph：实心椭圆 ↔ 上弧 ↔ 半闭缝 ↔ 小点。
4. **芽**：`emissive` 绿色 + 柔光 sprite 光晕；情绪时改变姿态（竖起/垂头/卷叶）作为第二表情通道。
5. **身体形变**：squash & stretch 走 scale 动画，接现有弹簧插值，保持"保留速度的阻尼感"。
6. **验收尺寸**：同一表情需通过 64px 头像、正常 2D 立绘、3D 正面/侧面、日夜光照四场景检查（沿用上午 review 的验收思路）。
